# DeCATS250 설치 파일

[최신 설치 파일 다운로드](https://github.com/rocosrex/decats250-releases/releases/latest)

Windows x64용 DeCATS250 설치 프로그램과 자동 업데이트 명세를 배포하는 저장소입니다.

- AutoCAD 2026 영문판 또는 한글판이 먼저 설치되어 있어야 합니다. AutoCAD LT는 지원하지 않습니다.
- 2.10.3 이하 버전에서는 2.10.4 이상의 설치 프로그램을 한 번 직접 실행하십시오.
- 이후 프로그램 시작 시 프로젝트를 열기 전에 새 버전을 확인하고 업데이트합니다.
- AutoCAD에서 CAD 모듈을 사용 중이면 업데이트를 보류합니다. AutoCAD를 종료한 후 다시 실행하십시오.
- 업데이트 시 기존 기준 데이터베이스를 보존합니다.

각 릴리스의 `DeCATS250-WPF-버전-win-x64-Setup.exe`를 실행하면 됩니다. `DeCATS250-update.json`은 프로그램이 사용하는 업데이트 명세입니다.
